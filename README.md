# A Garden for Dishaaaa ♡

A personalised flower garden made by Daksh.

## Publish with GitHub Pages
1. Create a repository (e.g. `garden-for-dishaaaa`).
2. Upload `index.html`, `style.css`, `script.js`, `README.md`, and the complete `assets` folder to the repository root.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch** → `main` → `/(root)` → Save.
5. Visit `https://YOUR-USERNAME.github.io/garden-for-dishaaaa/`.

Keep the `assets` folder beside `index.html`.
